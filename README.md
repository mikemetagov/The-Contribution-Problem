# The Contribution Problem

This repository will hold the public materials for a study of the contribution problem in DAOs and other organizations: the difficulty of matching recognition, rewards and decision rights to the people who create value, because contributions are hard to observe, attribute, value and sustain.

**Status:** The study was redesigned in October 2026. The new protocol and working files are private until publication.

**Archived Version 1:** the earlier public materials (a scoping-review protocol and Phase 1 templates) are preserved, unchanged, on branch [`archive/v1-scoping-review-2026-10`](https://github.com/mikemetagov/The-Contribution-Problem/tree/archive/v1-scoping-review-2026-10) (tag `v1-archived`). That version is no longer active.

Principal researcher: Michael Cooper (Metagov).
