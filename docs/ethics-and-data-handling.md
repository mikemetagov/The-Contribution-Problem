# Ethics and data handling
- Public sources only; no private channels (Discord, Telegram) and no contact with participants.
- Pseudonymous individuals reported only in aggregate; named attribution limited to authors of published works and formal public governance roles acting in role.
- Address-level on-chain data is published only as aggregated metrics per DAO-quarter; raw voter addresses are not republished.
- Excerpts ≤50 words with URL and archive link where possible.
- API terms and rate limits respected.
