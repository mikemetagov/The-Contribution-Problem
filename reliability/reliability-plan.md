# Reliability plan
- Pilot: 12 contrasting sources (T1–T5, ≥4 DAO types, RQ1 and RQ2 content), dual-coded independently.
- Statistics: Cohen's kappa and Gwet's AC1 (nominal; per option for multi-select), quadratic-weighted kappa (ordinal). Computed with `scripts/reliability.py`.
- Threshold: ≥0.70 per module on both nominal statistics; ≥0.70 weighted kappa for ordinal. Below threshold → versioned amendment and pilot recode (max two rounds); persisting failure is reported as a limitation with adjudicated values used.
- Full coding: all sources dual-coded; T4–T5 may fall back to single coding with a 20% double-coded check under the resource fallback (Protocol §12).
- Human audit: stratified random 10–15% sample at Gates 2 and 3; >20% disagreement in any module triggers module recode.
