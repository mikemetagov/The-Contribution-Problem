# Practitioner toolkit (to be completed in Phase 3, released after Gate 4)
Guidance for DAOs to run their own experiments on the contribution problem.

| File (planned) | Contents |
|---|---|
| `01-solution-menu.md` | Solution families S1–S7, mechanisms, contexts where they work, known risks |
| `02-design-parameters/` | One sheet per family: hypothesis, primary KPI, paired guardrail and rationale, minimum duration, comparison options, sample considerations, post-funding test, harms |
| `03-worked-designs/` | Two fully specified test designs |
| `04-kpi-guardrail-scorecard.md` | KPIs, reference ranges (public companies, cooperatives, best-performing DAOs), comparability notes |
| `05-stage-gates.md` | Pilot → modify → scale within → transfer checklists (≥2 governance quarters per stage; ≥1 quarter post-incentive persistence test) |
| `06-lean-and-full-templates/` | Lean (no analyst) and full (quasi-experimental/RCT) templates |
| `07-consent-and-ethics.md` | Consent, privacy and ethics of randomising incentives; survey instruments |
